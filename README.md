# 🚀 CodeLens - AI Code Explainer & Live Playground

An interactive, dark-mode web development playground built for developers and learners to write, execute, and analyze code in real-time, powered by Google Gemini API.

## ✨ Features

- **Split-Screen IDE:** Modern, clean dark-mode code editor paired with a live output terminal.
- **Live Browser-Based Sandbox:** Instantly run JavaScript snippets (like `.filter()`, `.map()`, `.reduce()` chains) and view formatted console outputs[cite: 1, 2].
- **AI Code Explainer:** Integrated with Google Gemini 2.5 Flash to provide plain-language walkthroughs, code complexity analysis, and bug detection[cite: 1, 2].
- **Pre-loaded Examples:** Built-in template selector to quickly test algorithms and data transformations[cite: 1, 2].

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS
- **AI Integration:** Google Gemini API (`gemini-2.5-flash`)[cite: 1, 2]
- **Deployment:** Bolt.host[cite: 1, 2]
- **Version Control:** Git & GitHub
